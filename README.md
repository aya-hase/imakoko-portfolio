# 🍽️ いまここごはんコンシェルジュ

ユーザーの希望（場所・時間・ジャンル・予算）と、データベースに蓄積された過去の履歴をもとに、AIが重複のない最適なお店を厳選して提案してくれるLINE Botアプリケーションです。

---

## 🌟 アプリ概要

「友達とご飯に行くお店を選びたいけれど、毎回同じお店になってしまう」「既存の検索サイトだと候補が多すぎて結局選べない」という日常の課題を解決するために生まれた、LINEで動くAI飲食店コンシェルジュです。

LINEの対話形式で条件を順番にヒアリングし、Next.jsのバックエンド連携によってホットペッパーグルメAPIから正確に対象店舗を検索。さらに、取得した店舗情報と「前回の履歴」をOpenAI APIに引き渡すことで、前回と被らない最適なお店を3件厳選し、LINE上に綺麗なカード形式（Flex Message）で提案します。

---

## ✨ 主な機能と特徴

* **💬 ステートフルな対話型ヒアリング**
  LINEという単発の通信（ステートレス）環境において、ユーザーの会話進捗（ステート）をバックエンドで管理。「場所」「予算」などの条件を順番に過不足なく聞き出します。
* **🧠 過去の履歴を考慮した「重複防止」選定**
  Supabase に保存された前回の履歴を読み込んで OpenAI API に渡すことで、前回提案したお店と被らない新しいお店を優先的に3件厳選して選んでくれます。
* **🗂️ 視認性の高いUI（Flex Message カルーセル）**
  AIが厳選した3件の検索結果は、スワイプできるカード形式でLINEにリプライ。店舗画像や詳細情報が一目でわかります。
* **🔒 安全なWebhook署名検証**
  LINEからの通信が本物かどうかを検証する署名検証を導入し、セキュリティを担保しています。

---

## 🛠️ 技術スタック

* **フロントエンド / バックエンド:** Next.js (Route Handlers), TypeScript
* **データベース / BaaS:** Supabase (PostgreSQL)
* **AI:** OpenAI API (gpt-4o-mini / プロンプトエンジニアリング)
* **外部API:** LINE Messaging API, ホットペッパー Webサービス API
* **開発環境:** ngrok (Webhook接続用)

---

## ⚙️ システム構成・データフロー

各APIがバケツリレー形式でデータを処理し、LINEユーザーへ提案を返すまでのデータフローです。

```
[ LINE ユーザー ]
│ (1) メッセージ送信 / 選択肢タップ
▼
[ LINE Webhook受信処理 (司令塔) ]
│
│ (2) ユーザーIDと入力を配送
▼
[ 会話状態（ステート）管理処理 ]
│ (3) 会話の進捗・条件の蓄積 ──> [ Supabase (DB) ]
│ (4) 「全条件が揃った」と判定したら次へ
▼
[ 店舗検索処理 ]
│ (5) 収集した条件でリクエスト
▼
[ ホットペッパー API ] ─── (6) 店舗リストの取得 ───┐
│
┌─────────────────────────────────────────────┘
▼
[ AI提案文・厳選生成処理 ] 
│
├─ (7) DBから「前回の履歴」を取得 ──> [ Supabase (DB) ]
│
│ (8) 店舗リスト ＋ 前回の履歴 をプロンプトに注入
▼
[ OpenAI API (gpt-4o-mini) ]
│ (9) 重複を避けた3件の厳選 ＋ 選定理由の生成
▼
[ LINE Webhook受信処理 ]
│ (10) Flex Message (カルーセル形式) を組み立て
▼
[ LINE Messaging API ] ─── (11) ユーザーにリプライ ───> [ LINE ユーザー ]

```
